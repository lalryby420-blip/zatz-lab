# 📡 Fake 3G Modem — مودم وهمي لرسيفر الدش

فكرة زطزاطية: رسيفرات الدش الصينية (Tiger، Starsat...) فيها خيار **3G** يقبل مودمات USB. الـ **ESP32-S3** يتظاهر إنه مودم **Huawei 3G**، والهدف النهائي إنه يوصّل إنترنت الوايفاي للرسيفر عن طريق **PPP + NAT**.

## 🗺️ المراحل

- [x] **المرحلة 1 (هذا الكود):** يتظاهر بمودم، يرد على أوامر AT، ويطبع كل اللي يبعته الرسيفر بالـ HEX
- [ ] **المرحلة 2:** خادم PPP + NAT على وايفاي الدار

## 🔌 الإعداد

| الإعداد | القيمة |
|---|---|
| Board | ESP32S3 Dev Module |
| USB Mode | **USB-OTG (TinyUSB)** |
| USB CDC On Boot | **Disabled** |

1. ارفع من منفذ **COM**، وافتح Serial Monitor على **115200**.
2. ركّب منفذ **USB الأصلي** في الرسيفر.
3. في الرسيفر ادخل لقائمة **3G** وحاول تتصل.

## 🆔 الهويات (`#define PROFILE`)

| القيمة | الهوية | VID:PID |
|---|---|---|
| 0 | Espressif عادي | 303A:xxxx |
| 1 | Huawei E1550 | 12D1:1001 |
| 2 | Huawei modem mode | 12D1:1506 |

## 📖 قراءة اللوق

| السطر | المعنى |
|---|---|
| `[USB] started` | الرسيفر شاف الجهاز ✅ |
| `>> AT...` | الرسيفر يحكي مع المودم الوهمي ✅✅ |
| `7E FF 7D 23 C0 21` | الرسيفر يبعت PPP — الفكرة تنفع 🎉 |
