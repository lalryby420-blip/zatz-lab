# 📶 CSI Radar V3 — كشف الحركة بالوايفاي

**ثلاث بوردات ESP32 تكشف الحركة في الغرفة من غير كاميرا ولا حساسات** — بس من الطريقة اللي جسم الإنسان يشوّش بيها إشارة الوايفاي (**Channel State Information — CSI**).

لوحة تحكم مباشرة على البورد الرئيسي تعرض الحالة، والروابط، وخريطة حرارية، وسجل الأحداث.

> ⚠️ **الحالة الصريحة:** الكود مكتوب بلا هاردوير ولا كومبايلر في البداية، وتصلحت فيه أخطاء كومبايل بعد التجربة على Arduino IDE. الدقة الحقيقية تعتمد على غرفتك وأماكن البوردات، ولازم تضبطها بروحك.

---

## 🧩 الهاردوير

| البورد | الدور | Node ID | الاسم |
|---|---|---|---|
| ESP32-S3 (CAM أو أي نوع) | Master | 0 | S3 |
| ESP32 DevKit V4 (WROOM) | Node | 1 | DEVKIT |
| ESP32-C3 | Node | 2 | C3 |

الكشف ما يحتاجش أسلاك ولا حساسات — الراديو متاع الوايفاي في الشيب بروحه. كل بورد على USB (5V).

**إضافات الماستر (اختيارية):** الكاميرا + **كرت SD** على بورد ESP32-S3 CAM:
- 🎥 **تسجيل أوتوماتيكي:** أول ما تتكشف حركة يبدا يسجّل فيديو AVI على الكرت، ويوقف بعد **5 دقايق بلا حركة** (ملف جديد كل 10 دقايق)
- 📺 **بث مباشر:** زر STREAM في لوحة التحكم (الكشف يوقف وقت البث باش البث ما يشوّشش)
- 📂 تحميل ومسح التسجيلات من لوحة التحكم
- أرجل الكاميرا والكرت معرّفة لبوردات **Freenove / ESP32-S3-EYE** — لو بوردك مختلف عدّل أسطر `CAM_PIN_*` و `CAMSD_*` بس
- يحتاج **PSRAM** (OPI PSRAM). بلا كاميرا ولا كرت، الكشف يخدم عادي

## ⚙️ الإعداد

- Arduino IDE 2.x + **esp32 by Espressif** نسخة **3.1.x** أو أحدث (ما فيش مكتبات إضافية)
- **DevKit:** `ESP32 Dev Module`
- **C3:** `ESP32C3 Dev Module` + USB CDC On Boot = Enabled
- **S3 Master:** `ESP32S3 Dev Module` + PSRAM حسب بوردك
- ترتيب الرفع: **S3 ← DEVKIT ← C3** — Serial Monitor على 115200

## 🚀 تشغيل سريع

1. شغّل الـ S3 — يعمل شبكة: **`CSI-RADAR-V3`** / كلمة السر **`RADARV3-123`** / قناة 6
2. شغّل DEVKIT و C3 — يشبكوا بروحهم (يعاودوا كل 3 ثواني)
3. اشبك التلفون على نفس الشبكة وافتح **http://192.168.4.1**
4. خلّي الغرفة ساكتة ~5 ثواني للمعايرة
5. امشي بين البوردات ← **MOTION DETECTED** 🎯

**نصائح التركيب (أهم من أي إعداد):**
- البوردات على ارتفاع 1–1.5 متر، والمسافة بيناتهم 2–4 متر، والحركة **بيناتهم**
- بعيد عن المعدن وزوايا الحيطان والراوتر
- لو حرّكت بورد، اضغط **Recalibrate**

## 🔬 كيف يخدم

### الشبكة والروابط
- الـ S3 هو نقطة الوصول (AP)، والعقد تشبك عليه على القناة 6
- **6 روابط اتجاهية** بين الثلاث بوردات. كل بورد يبعت إشارات صغيرة بـ **ESP-NOW**، واللي يستقبلها ياخذ CSI متاع الرابط

### جدولة بالوقت (TDM)
- إطار 30ms مقسوم 3 خانات × 10ms — كل بورد يبعت في خانته بس
- الساعات تتزامن مع الماستر
- الإشارات بسرعة **6 Mbps OFDM** — لأن 1 Mbps الافتراضي ما يعطيش CSI
- شكل الإشارة (10 بايت): `0xC5`، رقم البورد، رقم تسلسلي، وقت المرسل

### معالجة CSI (بيانات حقيقية، مش محاكاة)
1. يقرا CSI (أزواج تخيلي/حقيقي، حتى 64 subcarrier)
2. السعة = `sqrt(re² + im²)`
3. يقسم على متوسط الحزمة (يلغي تغيّر الكسب الأوتوماتيكي)
4. `metric` = متوسط الفرق المطلق مع الحزمة اللي قبلها
5. متوسط كل 100ms ← **رقم أكبر = حركة أكثر**

### الكشف (على الماستر)
- **معايرة:** أول 50 قراءة (~5 ثواني) تبني الخط الأساسي
- **العتبة:** `mean + max(ks·σ, kr·mean, 0.002)` حيث `ks = 6 − 0.5·S` و `kr = 0.30 − 0.025·S`
- **تأكيد:** 2–3 قراءات متتالية فوق العتبة — قراءة وحدة مزعجة ما تشغّلش الإنذار أبداً
- الحركة تبقى 1.5 ثانية بعد آخر قراءة، و1 ثانية راحة
- النظام **ما يقولش NO MOTION** إلا لما يكون عنده 4 روابط مستقرة على الأقل

## 📊 لوحة التحكم

- لافتة الحالة الكبيرة، وعدّاد الأحداث، ودرجة الشذوذ (0–100)
- شريط **الحساسية** (1–10، ابدا بـ 7) + Recalibrate + Clear
- **خريطة حرارية** لكل بورد: أزرق = مستقر ← أحمر = تغيّر عالي
  *(هي تغيّر الإشارة، مش صورة حرارية ولا مكان الشخص)*
- كروت البوردات، والروابط، ورسم بياني مباشر، وآخر 10 أحداث

| Endpoint | الوظيفة |
|---|---|
| `GET /` | لوحة التحكم |
| `GET /data` | JSON بكل الحالة |
| `POST /recal` | إعادة المعايرة |
| `POST /clear` | مسح الأحداث |
| `POST /sens?v=N` | الحساسية 1..10 |
| `GET /files` | قائمة التسجيلات |
| `POST /del?f=NAME` | مسح تسجيل |
| `GET :81/stream` | البث المباشر (MJPEG) |
| `GET :81/dl?f=NAME` | تحميل تسجيل |

## 🧪 الاختبار

1. انتظر لين كل البوردات **CONNECTED**
2. كل رابط لازم يكون ~30+ csi/s وفقدان أقل من 10%
3. فرّغ الغرفة ← Recalibrate ← 100%
4. تأكد إن NO MOTION مستقر دقيقة
5. امشي بين البوردات ← لازم MOTION DETECTED

## 🔧 مشاكل شايعة

| المشكلة | الحل |
|---|---|
| خطأ في `wifi_csi_config_t` | نسخة core جديدة غيّرت أسماء الحقول |
| `esp_wifi_config_espnow_rate` ما يتكمبلش | استعمل `esp_now_set_peer_rate_config()` مع `WIFI_PHY_RATE_6M` |
| العقد ما تشبكش | تأكد من اسم الشبكة والباسورد والـ S3 شغال |
| حركة ديما | نزّل الحساسية، وبعّد المراوح والشاشات |
| ما فيش حركة أبداً | علّي الحساسية، وقرّب البوردات، وتأكد إن الحركة تقطع الخط بيناتهم |

## ⚠️ الحدود (بصراحة)

- التأخير الحقيقي ~0.3–0.6 ثانية، مش أقل من 200ms
- CSI حساس للضجيج: مراوح، أجهزة وايفاي ثانية، أشياء تتحرك
- ما يكشفش التنفّس ولا الحضور الساكن، وما يفرّقش بين إنسان وحيوان
- الحساسية ترجع 7 بعد إعادة التشغيل
- 🎥 الكاميرا تسجّل ناس — استعملها في مكانك انت، واحترم خصوصية اللي حولك
