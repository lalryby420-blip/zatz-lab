# ⌨️ ZatzKey — كيبورد وماوس من التلفون

الـ **ESP32-S3** يولّي **كيبورد وماوس USB حقيقيين**. تركّبه في أي كمبيوتر (ويندوز، لينكس، كالي...) وتتحكم فيه من صفحة ويب على التلفون.

اتعمل لحل مشكلة حقيقية: لابتوب كيبورده خارب وواقف عند شاشة الباسورد.

## ✨ المزايا

- كتابة مباشرة: كل حرف تكتبه في التلفون يطلع على الكمبيوتر
- صندوق نص تبعت منه أوامر كاملة (+ Enter)
- أزرار: Esc، Tab، Enter، الأسهم، Home/End، F1–F12...
- اختصارات جاهزة: تيرمينال (Ctrl+Alt+T)، نسخ/لصق، Alt+Tab، Alt+F4
- لوحة ماوس باللمس + كليك يمين/يسار + سكرول
- يخدم بلا تعريفات، والجهاز يشوفه كيبورد عادي

## 🔌 الإعداد

**Arduino IDE → Tools:**

| الإعداد | القيمة |
|---|---|
| Board | ESP32S3 Dev Module |
| USB Mode | **USB-OTG (TinyUSB)** |
| USB CDC On Boot | **Disabled** |
| Flash Size | 16MB |
| PSRAM | OPI PSRAM |

1. عدّل `WIFI_SSID` و `WIFI_PASS` (اختياري).
2. ارفع الكود من منفذ **COM** (اللي فيه شيب CH343/CP2102).
3. ركّب منفذ **USB الأصلي (OTG)** في الكمبيوتر اللي تبي تتحكم فيه.

## 📱 الاستعمال

- اشبك التلفون على وايفاي **ZatzKey** — كلمة السر `zatz1234`
- افتح **http://192.168.4.1**
- أو من وايفاي الدار: الـ IP يطلع في الـ Serial Monitor

## ⚠️ الحدود

- يكتب **إنجليزي بس** (الكيبورد USB يبعت أزرار، مش حروف)
- غيّر كلمة سر شبكة ZatzKey قبل الاستعمال الجدي — أي واحد يدخل للشبكة يقدر يكتب على جهازك
- الشغل في الـ BIOS وقائمة GRUB **مش مضمون** على كل الأجهزة
